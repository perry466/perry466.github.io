## 使用 `certificate-manager` 重新生成证书

```
/usr/lib/vmware-vmca/bin/certificate-manager
```

![[Pasted image 20260904084627.png]]

这里我选的是8，全部更新，要注意下面三个地方，需要填写vCenter的ip地址，主机名不能只写短主机名（photon-machine），应该写photon-machine.local，然后需要查看或修复一下host文件
![[Pasted image 20260904084729.png]]

另外开一个ssh端口，查看对应服务是否跑起来了

```
service-control --status --all
```

![[Pasted image 20260904085414.png]]

然后耐心等待结果
![[Pasted image 20260904085525.png]]

![[Pasted image 20260904085544.png]]

出现100%successful就代表部署完成了，此时可以输入你的https://ip登录web端，也可以用上面的查看证书的命令看一下证书的有效期是否增加，一般为两年时间
