第三次全站换配色时，我终于把颜色全部挪进了一个文件。

## 只有一个来源

```css
:root {
  --color-bg: #fcfcfa;
  --color-text: #1b1f24;
  --color-muted: #525c68;
  --color-accent: #9e3b2b;
  --space-4: 1rem;
  --radius-sm: 6px;
}

[data-theme="dark"] {
  --color-bg: #14171a;
  --color-text: #e7e5e0;
  --color-muted: #a6adb6;
  --color-accent: #e08a72;
}
```

组件里只写 `var(--color-text)`，永远不写十六进制值。这样「深色模式」不是一套额外的样式，而只是同一套变量换了一组值。

## 为什么有效

- 换配色改一处，风险可预期。
- 深色模式不需要复制整份样式表。
- 设计评审时讨论的是「主色偏冷还是偏暖」，而不是某个按钮上的色号。

> [!IMPORTANT]
> 暗色不是把亮色反相。同一组语义变量在两套主题里要有各自的取值，尤其强调色的亮度对比——亮色主题里的深红，放到暗色背景上几乎看不见。

## 一条边界

令牌管的是**设计值**：颜色、字号、间距、圆角、阴影、动效时长。它不该管具体组件的选择器。一旦令牌文件里出现 `.btn-primary`，这个边界就破了，接下来会不可逆地退化成一个巨大的样式表。
